# assets-src — model source drop zone

Put purchased/generated model files here. This folder is **source material only** —
nothing in it ships. The game stays a single self-contained `index.html`; the chosen
model gets optimized and embedded there as base64.

## Expected drops

1. **RenderHub Cairn Terrier** (Nyilonelycompany) — the full downloaded package
   (zip or extracted folder, ~439 MB). Contains .blend / FBX / OBJ / **GLB** / USDZ
   + 4K PNG textures. The GLB + textures are what will actually be used.
   License: RenderHub Extended Use (web games explicitly permitted). Keep the
   purchase receipt/license info alongside if convenient.

2. **Meshy exports** — rigged + animated **GLB** exports of generated Ludo models
   (one file per attempt is fine, e.g. `ludo-meshy-v1.glb`, `ludo-meshy-v2.glb`).
   License: paid-tier outputs are owned by the purchaser.

After dropping files in, just say so in the session — processing (white retexture,
texture downsizing, decimation, animation-clip audit, base64 embed) happens from here.
